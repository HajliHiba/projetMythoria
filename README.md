Mythoria is a Dark Fantasy trading card game developed using HTML5, CSS3, Tailwind CSS, and JavaScript. The project is divided into two parts. The first part allows players to explore the game, purchase boosters, open random cards, manage their collection, and build their own deck using LocalStorage. The second part introduces an interactive battle arena where players choose between Light and Darkness factions, summon creatures, attack opponents, manage health points, and fight against a simple bot opponent. The game uses JavaScript to organize the code and separate the interface, game state, utilities, and combat logic. The project is deployed on Vercel.
the knowledge we use in this project is; HTML5, CSS3, Tailwind CSS, JavaScript, LocalStorage, JSON, Git, GitHub, and Vercel.
